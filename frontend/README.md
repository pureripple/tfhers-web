# TFHers frontend (scaffold only)

Clean Vue 3 + Vite + Vue Router + Pinia. User routes under `/`, admin under `/admin`.

No legacy static HTML/CSS/JS/images are copied here. Old resources stay in
`tfhers-web-app` / `tfhers-web-management` until the Vue migration is finished.

## Commands

```bash
cd frontend
npm install
npm run dev
npm run build
```

Dev: http://localhost:5173
